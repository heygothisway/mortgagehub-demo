# MortgageHub 展示版（貸回來了沒？）

這個資料夾是供需求方試看流程的靜態展示版，沒有後端、登入或跨裝置同步。資料只存在各自瀏覽器的本機儲存空間。

## 公開展示注意事項

- GitHub Pages 網站會公開給網際網路上的任何人；請只使用範例資料，不要輸入真實客戶、銀行或房仲資料。
- 請只上傳本資料夾內的 `index.html`、`styles.css`、`app.js` 與本 README，不要一併上傳需求討論稿、LINE 對話、照片或客戶文件。
- 不要將密碼、API 金鑰或其他機密放進原始碼。

## 發布方式

1. 在 GitHub 建立一個獨立的公開儲存庫，例如 `mortgagehub-demo`。
2. 將本資料夾中的檔案放在儲存庫根目錄。
3. 到儲存庫的 **Settings → Pages**，選擇從 `main` 分支的根目錄發布。
4. 等待 GitHub Pages 顯示網站網址，再把網址提供給需求方。

每位使用者在自己的瀏覽器看到獨立的本機資料；這只是流程原型，不適合承載實際案件。
